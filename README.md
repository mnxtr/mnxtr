## How I approach engineering

I prefer building systems where the architecture matters beyond the UI:

```text
Problem
   ↓
Domain & Data Model
   ↓
API / Service Architecture
   ↓
Implementation
   ↓
Testing
   ↓
Security & Failure Handling
   ↓
Deployment
   ↓
Measurement & Iteration
```

For AI applications, I focus on integrating models into usable software rather than treating the model itself as the entire product.
